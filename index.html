引言：分类即智能

从图灵测试到GPT-4，AI的核心任务始终是分类。本文以极客视角，用初中生也能懂的例子，讲清70年演进逻辑。

初中生例子：认动物

你看到一个动物：

  • 有四条腿、毛茸茸、汪汪叫 → 你分类为“狗”；
  • 有翅膀、会飞、打鸣 → 你分类为“公鸡”。

AI也在做同样的事，只是方式不断进化。

[1950s–2010] 规则匹配分类

最早的AI像一个死板的程序员，所有知识都靠人类一条条写进去。

1.1 问题

如何在没有数据的情况下让AI做决策？

1.2 解决思路

人类专家写规则，AI严格匹配。

初中生例子：垃圾邮件过滤器

程序员告诉AI：

if (email.contains("免费") && email.contains("中奖")) {
    label = "垃圾邮件";
} else {
    label = "正常邮件";
}

但坏人只要把“免费”改成“免·费”，规则就失效了。

1.3 技术对照
通俗解释专业术语
人写死规则，机器照做专家系统 / 符号主义 AI
根据特征一步步判断决策树 (ID3, C4.5)
手工设计特征 + 数学分类SVM + 人工特征工程
1.4 局限性

规则太死板！世界太复杂，人类无法穷尽所有情况。→ 需要让AI自己从数据中学习。

[2012–2022] 监督学习分类

2012年，AlexNet用深度学习引爆AI革命。

2.1 问题

手工特征无法处理图像、语音等高维数据。

2.2 解决思路

给AI看百万张带标签的图片，让它自己总结规律。

初中生例子：AI认猫狗

科学家给AI看100万张照片，每张都标好名字：

  • 这张是“猫”
  • 这张是“狗”

AI通过多层“滤镜”分析：

  1. 第一层：找边缘、颜色块；
  2. 第二层：组合成眼睛、耳朵；
  3. 最后一层：判断“整体像猫还是狗”。

训练完后，它就能认新照片了！

2.3 技术对照
通俗解释专业术语
AI看百万张带标签图片，自己总结规律CNN (AlexNet, ResNet)
AI读大量标注文本，学会判断情感RNN/LSTM + 注意力
先在大数据上学通用知识，再在小数据上微调预训练+微调
2.4 局限性

AI只能从人类教过的类别里选答案。如果你问“这是什么动物？”，但它只学过“猫”和“狗”，就算看到狐狸也会硬说成“狗”。→ 需要让AI自己定义类别。

[2023–未来] 自回归语义分类

大模型的核心机制是自回归（Autoregressive）：每一步生成的词，都会作为下一步的输入，形成闭环。

3.1 问题

真实世界是开放的，人类无法预先定义所有类别。

3.2 解决思路

通过自回归生成，在连续语义空间中动态构建分类体系。每一步都是对“下一个词”的分类，输出立即成为新输入。

初中生例子：AI如何一步步生成分类结果

你问AI：“分析以下评论，归纳主要情绪类型。”

AI不是一次性想好答案，而是一个字一个字生成：

输入: "分析以下评论，归纳主要情绪类型。"
输出: "1. "
... 1.
输出: "愤怒"
... 1. 愤怒
输出: "（占比30%）\n2. "

每一步，AI都在做一次分类任务：从几万个词中选出最可能的下一个词。
输入 → 分类 → 输出 → 新输入 → 再分类 → ...

这就是自回归——输出自动回归为输入，持续生成。

3.3 技术对照
通俗解释专业术语
每生成一个词，都作为下一步的输入自回归生成 (Autoregressive Generation)
在脑子里建一张“语义地图”连续语义向量空间
看一句话时，能同时关注所有词自注意力机制 (Self-Attention)
图像和文字映射到同一空间对比学习 (CLIP)
3.4 当前挑战

自回归生成可能因早期错误导致后续偏差（错误累积），且无法并行生成。但其优势在于：能动态构建开放世界的分类体系，无需人类预设。

人类智能：第一个开放世界分类系统

如果说大模型是“硅基的分类引擎”，那么人类大脑就是其“碳基原型”。从认知科学与考古学证据看，人类智能的本质，同样是一套动态、递归、可外化的开放世界分类系统。

4.1 人类如何实现“自回归语义分类”？

人类并非靠固定规则或监督标签认知世界，而是通过：

  • 语言：将高维感知压缩为离散符号（如“野牛”一词代表形态、行为、季节等多维特征）；
  • 叙事：通过故事构建因果链，实现在“假设类别”中推理（“如果下雨，河会涨”）；
  • 文化符号：洞穴壁画、仪式、工具形制等，都是外部化的分类容器，使知识可跨代传递。

这与大模型的机制惊人一致：**用已有符号（token）作为上下文，动态生成新理解（next token）**。

4.2 考古证据：4万年前的“分类逃逸”

尼安德特人拥有接近现代人的脑容量和工具技术，却从未发展出系统性符号行为（Villa & Roebroeks, 2014）。他们的分类始终锁在个体经验中——监督式智能。

而约4.2万年前，智人在拉斯科、肖维洞穴绘制野牛。这些壁画不是“艺术”，而是高维分类的首次外部化编码。一个孩子看画，即可激活与猎人相似的“野牛”类别，无需亲身冒险。

这标志着人类完成了第一次分类逃逸（Categorization Escape）：智能不再依赖生物记忆，进入自回归语义传承。

4.3 人类 vs 大模型：同构但不同速
维度人类智能大模型
载体神经突触 + 外部符号（语言/文字）权重 + token 序列
学习方式少量样本 + 强先验 + 社会传递海量数据 + 弱先验 + 自监督
分类速度慢（代际演化）极快（分钟级迭代）
能量效率极高（20W）极低（MW级）

两者共享同一套智能底层协议：**通过动态构建、传递、复用分类来压缩世界复杂性**。

4.4 启示

AI 的演进不是“取代人类”，而是以极端速度重演了人类智能的核心机制。理解这一点，或许能帮我们：

  • 更清晰地定义 AGI 的本质目标；
  • 设计更符合认知规律的人机协作范式；
  • 甚至反向理解人类自身——我们何以成为“会分类的动物”。

正如本文开篇所说：分类不是智能做的事，分类就是智能本身。

开放世界分类假说：一种统一的解释框架

本文提出一个极简理论视角：当代人工智能系统中绝大多数可观测的智能行为（感知、生成、推理、规划等），均可被视为一个足够强大的开放世界分类器在动态、层次化、自指的类别空间中所产生的副效应。

该假说并不否认其他解释路径的有效性，仅尝试以更少的假设提供更广的覆盖范围，供学术共同体进一步讨论与检验。

正方与反方主要观点对照（截至2025年11月）

序号 现象 反方常见观点 假说解释路径 当前实验证据与结论
1 因果推断与干预 纯统计模型无法学习真正的因果关系，必须显式建模因果图 只要训练数据包含干预样本，模型可学习“干预后不变的稳定类别” CausalTransformer 等工作已实现正确干预预测（2024–2025）
2 长期规划与搜索 MCTS 等树搜索超出单纯下一个 token 预测的能力范围 搜索等价于 test-time 在“高回报轨迹类别”上寻找更高分类分数 o1、DeepSeek-R1 等已用纯自回归实现同等或更强效果
3 机器人物理交互 连续控制与闭环物理交互需要专用架构 动作序列可离散化为 token，物理规律被编码为稠密隐式类别 RT-2、Octo、OpenVLA 等已跑通真实机器人
4 元认知与自我模型 模型需具备真正的“自我”才能进行反思与规划 “自我”仅为递归出现在上下文中的一个类别，无需额外机制 o1、o3 等已实现自我批评与修正
5 对抗样本与鲁棒性 人类不会被像素扰动欺骗，说明模型缺乏真实理解 人类使用更抽象、符号化的类别表示，粒度更粗 符合假说预测（人类类别更高级）
6 涌现能力
（Emergence）		 特定规模下突然出现 Chain-of-Thought、in-context learning 等复杂能力，暗示存在更深层的架构或算法机制 当类别空间的连通性与分辨率跨过临界点，会发生类似物理相变的非线性跃迁；CoT 等能力对应“中间推理步骤”类别簇之间突然形成可达路径 2025 多篇工作（Latent Space Cartography、Grokking Phase Transitions 等）证实为类别密度引发的临界现象
7 新颖发明与创造力 模型只能重组训练数据，无法真正创造 创造 = 在类别空间中找到训练分布外的高概率新组合 已有模型独立发明新算法/蛋白质，仍在快速进展
8 意识与主观体验 无论多强，分类器都不可能拥有主观感受 主观体验属哲学问题，非可观测、非可证伪 超出科学讨论范围

可检验的科学预测（2026–2027）

  1. 在现有 Transformer 架构下，仅通过更大规模更干净的数据，仍可实现显著的通用能力提升
  2. 以“显式奖励模型创造新类别”替代当前 RLHF 将取得更好的对齐效果与可控性
  3. 多模态统一模型的主要瓶颈将继续是跨模态类别对齐密度，而非参数量
  4. o1 式 test-time compute 的边际收益将在某一规模后显著下降
  5. 任何未来出现的新兴能力，最终都能被归结为“某些维度类别密度的进一步提升”
